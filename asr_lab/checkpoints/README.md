# 学习检查点

检查点把每个实现任务转化为可以独立复现的学习记录。一个检查点只回答一个主要问题，失败或阻塞也要如实记录，不能只保留成功结果。

## 使用方法

1. 复制 `TEMPLATE.md`，按 OpenSpec 任务顺序创建三位数字前缀文件。
2. 开始实现前填写目标、核心概念、入口命令和预期结果。
3. 运行后粘贴必要的实际输出，写明解释和遇到的问题。
4. 逐项核对进入下一步的条件；不满足时保持当前任务未完成。

## 状态值

- `in-progress`：正在实验，证据尚未完整。
- `complete`：目标和下一步条件已经由证据验证。
- `blocked`：存在无法在当前范围内解决的阻塞，记录原因和所需条件。
- `exited`：候选未通过能力或部署门槛，保留合规退出证据。

不要改写旧记录中的实际输出。若发现记录错误，应追加更正说明并引用新的证据。
